# Updates 2026-11-16_11-42-42: review and click-through of the date-based solar-system flights

Follows `UPDATES_2026-11-16_07-32-23.md`. No physics changed. Nothing committed.

## Changed files and functions
- `src/components/playback/SpeedChart.tsx`
  - `Geometry.scale` is now `{ slowest, fastest }` (was `{ floor, top }`).
  - `makeGeometry`, orbit and spiral branch: the line is mapped straight onto the strip between the two labels,
    `y = base - ORBIT_BOTTOM - clamp((v - low) / (top - low), 0, 1) * lineSpan`. The derived "baseline speed"
    (`floor`) is gone; it could clamp to 0 and produce the label "Baseline 0 km/s, not zero".
  - Labels read "Fastest 33.6 km/s" and "Slowest 20.8 km/s" (the true extremes of the flight).
- `src/styles/playback.css`: comment on `.playback-chart-scale` only.
- `src/components/visualizer/OverlayDriver.tsx` (flight markers, ship and speed tag block of the frame loop)
  - The speed text is written to the tag's inner `.map-shiptag` element. It used to be written to the anchor
    element, which deleted the inner element, so the tag showed as bare, uncentred text. This defect is also
    in the version on the live site.
  - The tag tries four spots in order (below the path at 36 px, above at 36 px, below at 60 px, above at 60 px)
    and takes the first that does not hit a label or ring. Before, the fallback spot was never checked.
- `src/components/plan/WhenSection.tsx`: the over-budget warning no longer says "This is the cheapest launch
  found" when the flight was picked on the launch-window chart (it is not the cheapest then).
- `src/components/shell/BottomSheet.tsx`, `snapHeight`: full height is `vh - 114` (was `vh - 72`), so the phone
  sheet stops below the "Solar system / Stars" switch instead of sliding under it.
- `CLAUDE.md`, `HANDOFF.md`, `LOG.md`: updated.

## Verified (headless Microsoft Edge, software renderer, production build)
- 1440 px wide: speed chart for chemical rocket to Mars, chemical rocket to the Moon, ion drive to Neptune
  (labels clear of the line by measurement); launch-window chart hover, click, "Soonest arrival instead",
  arrow keys and Enter; month buttons, "Today", typed date; "Fly past" and back; fuel-budget slider by keyboard;
  a whole chemical flight to Mars played at 4x to "Arrived"; reduced-motion setting (no running animations,
  playback still advances); Earth to Moon map with its arrival marker; speed tag beside the origin label.
- 390 px wide: launch-window chart inside the bottom sheet, tap to pick a flight, 44 px buttons, no sideways overflow.
- No console errors in any run. `npx tsc --noEmit` clean, 178 Jest tests pass, `npx vite build` succeeds.

  the new earliest date; it does not go back to the date chosen before the pick.
- The fuel-budget slider moves about 0.01 km/s per arrow key (Page Up and Page Down take bigger steps).
- With the phone sheet at full height only about 40 px of map remains, and the map's zoom buttons crowd into it.
- On the Earth to Moon map the Moon's orbit line, seen nearly edge-on, runs through the arrival caption.
- Page addresses for the chemical rocket still carry the unused `a` and `v` values.
- `npx vite build` fails from Git Bash with "No matching HTML proxy module found" (drive-letter case); it works
  from PowerShell with the path written `E:\...`.
