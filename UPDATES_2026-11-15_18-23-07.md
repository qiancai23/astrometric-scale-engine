# UPDATES 2026-11-15 18:23 — Redesign build ("Plan it, then fly it")

Technical record of the redesign build. Design background: `UIUX/DESIGN_REVIEW_2026-11-15.md`. The contract every part was built against: `UIUX/BUILD_SPEC_2026-11-15.md`. Screenshots of the result: `UIUX/build-2026-11-15/`.

## What changed, in one paragraph
The fixed three-column dashboard was replaced by a full-window 3D map with floating panels: a flight plan panel (searchable target pickers, five engine cards, tuning sliders), an answer panel (ship clock against Earth clock, plain-language comparisons), and a playback panel (play button, live readouts, a speed chart that is also the scrubber, famous flights). Phones and tablets get a bottom sheet. The flight is stored in the page address. The antimatter rocket's speed limit rose from 0.99 c to 0.999 c. `src/physics/kinematicsEngine.ts` was not changed.

- `src/components/Dashboard.tsx`, `GlobalHeader.tsx`, `FlightConfig.tsx`, `TelemetryHUD.tsx`, `charts/KinematicCharts.tsx`, `visualizer/SceneGraph.tsx` (all recoverable from git commit `ef8fbd6`).

## Foundation (shared modules)

### `src/types.ts` (new)
`AstroObject`, `DriveCore`, `AstrometricRegime`, `SublightEngineId`, `EngineId`, `Endpoint`, `FlightSpec` (`from`, `to`, `engine`, `a`, `v`, `w`, `m`), `MapLayers`. Import-free to avoid cycles.

### `src/data/engines.ts` (new)
- `ENGINES`: chemical (0.01–3 g, 1–30 km/s), ion (0.001–0.1 g, 0.001–0.01 c), fusion (0.01–1 g, 0.02–0.2 c), antimatter (0.01–3 g, 0.1–**0.999 c**), warp (factor 1–50). Each sublight engine has `defaultG`, `defaultC`, `speedScale` (`'linear'` or `'nines'`), `speedInKms`.
- Slider mappings, all 0..1: `speedToSlider` / `sliderToSpeed` (the `'nines'` scale is linear in −log10(1−v/c), so 0.9, 0.99 and 0.999 are evenly spaced), `accelToSlider` / `sliderToAccel` (logarithmic), `massToSlider` / `sliderToMass` (logarithmic, 25 t to 50 million t).
- `compareEngines(distance, mass, settings, warpFactor)`: runs `KinematicsEngine` for all five engines and returns Earth time, ship time, peak speed and `logFraction` (position on a shared log10 bar; floor = fastest trip minus 0.35 decades, at least one decade of range, clamped to 0.04..1).
- `clampSublightSettings`, `defaultEngineSettings`, `shipClass`, `accelFeel`, constants `GRAVITY`, `C_TO_KMS`, `C_TO_KPH`, `MIN_MASS_KG`, `MAX_MASS_KG`.

### `src/physics/flightProfile.ts` (new) — moment-by-moment flight model
`buildSublightProfile({distance, acceleration, velocityCeiling})` and `buildWarpProfile(distance, warpFactor)` return a `FlightProfile` with `at(t)`, `atFraction(f)`, `fractionAtDistance(d)`, totals, `accelTime`, `coastTime`, `accelDistance`, `hasCoast`, `peakVelocity`, `peakGamma`, `accelEndFraction`, `decelStartFraction`, `timeGap`.
Math (same model as `KinematicsEngine`, tested to agree to 1e-7): with e = a·t/c during a burn from rest, v = c·e/√(1+e²), x = (c²/a)(√(1+e²)−1), τ = (c/a)·asinh(e), γ = √(1+e²). The braking burn is the mirror image. Coast: τ advances at 1/γ_peak.
Numerical care: √(1+e²)−1 is computed as e²/(1+√(1+e²)); `timeGap` (Earth time minus ship time) uses the series e³/6 − 3e⁵/40 + 15e⁷/336 for e < 0.01 and β²/(1+√(1−β²)) for the coast, so sub-second gaps on slow flights are accurate.
Chart helpers: `sampleProfile(profile, count, axis)`, `chartPosition(profile, f, axis)`, `fractionFromChartPosition`. The `'log'` axis is logarithmic in "time to the nearer end of the flight", mirrored about the midpoint, spanning 1.5 to 9 decades chosen so the burn is visible.

### `src/data/catalog.ts`, `src/data/constellations.ts` (new)
Normalizes `scripts/systemic.json` (27 objects) and `scripts/stars.json` (3,003) into `CatalogEntry` records: friendly names (`Eps Eri` → `Epsilon Eridani`), slugs, kind, spectral class and plain star type, physical display color, magnitude, distance from Sol, full constellation name, exoplanet host, aliases (hand table for famous objects), prominence, one-line description. `searchCatalog` ranks exact > name prefix > word prefix > alias > substring > constellation/kind, with typo tolerance (Damerau-Levenshtein 1 or 2) when fewer than 3 hits. Also `browseGroups`, `labelCandidates`, `findBySlug`, `getEntry`, `entriesFor`, `catalogSize`. JSON is imported with `import * as` plus an `unwrapJson` helper because Jest compiles to CommonJS without `esModuleInterop`.

### `src/state/useFlightStore.ts` (rewritten, old API kept)
- Kept: `setRegime`, `setDriveCore`, `setOrigin`, `setDestination`, `setShipParams`, `distanceMeters`, `sublightResult`, `warpResult`.
- Added state: `engineId`, `engineSettings` (per-engine memory of acceleration and speed limit), `profile`, `comparison`, `flightRevision`, `routeRevision`, `playing`, `progress` (0..1 of Earth time), `playbackRate`, `arrivalCount`, `hasFlown`, `layers`, `selectedId`, `hoveredId`, `beaconId`, `focusRequest`, `picker`, `toast`.
- Added actions: `setEngine`, `setEndpoint(which, id)` (same map: set, or swap if it equals the other end; other map: switch map, keep the other end if it exists on both maps (Sol), else that map's default), `swapEndpoints`, `switchRegime`, `loadFlight(spec)` (resets all engine tuning to defaults first), `play`, `pause`, `togglePlay`, `seek`, `advance`, `setPlaybackRate`, `toggleLayer`, `selectObject`, `setHovered`, `setBeacon`, `focusObject`, `frameFlight`, `openPicker`, `showToast`, `dismissToast`.
- `derive()` is the only place physics runs for the active flight. Any change to the flight stops and rewinds playback.
- Initial state: a flight parsed from `location.search`, else `DEFAULT_FLIGHT` (Earth to Mars, fusion, 1 g). Exports `specFromState`, `selectResult`, `openedFromSharedLink`, `PLAYBACK_BASE_SECONDS` (24), `PLAYBACK_RATES`.

## Defects from the design review, and what happened to each
All 13 are closed: literal `γ` (the header is gone); clipped chart (new chart measures an always-mounted wrapper); `0.11000000000000001c` label (all labels go through `format.ts`); undefined CSS variables (one token set); colliding section headings; unusable on phones (bottom-sheet layout, no horizontal overflow at 390 px); engine change left the speed at the bottom of the range (per-engine defaults and memory); "Midpoint Flip" on coasting flights (captions come from `profile.hasCoast`); search ignored the category filter (one search); hard-coded departure date (removed); `kkm` unit (removed); no favicon or description (added); three product names (one).

## Not verified / technical debt
- Not seen on a real graphics card, a real phone, Firefox or Safari. Star size, halo strength, twinkle and camera feel were tuned only against the software renderer.
- Not tested with a screen reader. Reduced-motion paths exist but were not exercised.
- Build output: `three` chunk 1.04 MB (288 KB gzip), `catalog` chunk 1.0 MB (204 KB gzip), app 96 KB, map 48 KB. The catalog still loads before the interface appears (behind the boot screen); loading `stars.json` on demand would speed up first paint.
- `scripts/stars.json` has no 61 Cygni and stores Epsilon Eridani as `Ran`. Search handles the latter by alias.
- With the 0.999 c limit, "1 g to Andromeda" is about 114,000 ship-years, not the 28 years of an unlimited 1 g flight.
- Warp energy is still the placeholder model; the answer panel labels it "notional".
- `src/scripts/*.json` remain unused duplicates of `scripts/*.json`.
- The object card on the map can cover the origin or the path when the selected star is near them.
- Nothing is committed or deployed.
